# template saas web

## ⚙️ Configuração do Ambiente 
Para executar o projeto independente do ambiente:
```bash
# para rodar em dev
cd /tsaas-web
npm run dev 

# para rodar em prod
cd /tsaas-web
npm run build
npm start
```

🚨 Atenção: requisito necessario para rodar o projeto
```bash
# instalar dependencias do node
npm install 
```
